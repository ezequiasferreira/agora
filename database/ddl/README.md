# Definições SQL do Banco Ágora

Esta pasta concentra os scripts SQL responsáveis pela criação da estrutura do PostgreSQL utilizada no MVP.

## Organização prevista

- `01_schema.sql` — criação do schema `agora`;
- `02_remuneracoes.sql` — estrutura da tabela de remunerações;
- `03_tlp.sql` — estruturas relacionadas à TLP;
- `04_rubricas.sql` — estrutura da tabela de rubricas.

Os scripts devem permitir reconstruir a estrutura do banco sem depender de criação manual no DBeaver.

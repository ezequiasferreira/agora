# Integração do MVP Ágora

Esta pasta concentra os testes de integração entre os módulos do projeto.

O objetivo é validar o fluxo completo:

Pergunta em linguagem natural
→ geração de SQL
→ validação pela API
→ consulta ao PostgreSQL
→ retorno estruturado
→ resposta final ao usuário.

Esta área é compartilhada pela equipe e será usada principalmente para os testes de ponta a ponta do MVP.

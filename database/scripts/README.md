# Scripts de Banco de Dados

Esta pasta concentra os scripts utilizados para preparar, carregar, validar e diagnosticar os dados do PostgreSQL utilizados no MVP do Ágora.

## Scripts previstos

- carga das remunerações do TJRR;
- diagnóstico de integração TLP × remuneração;
- carga da TLP;
- carga das rubricas da folha;
- validações de consistência dos dados.

Os arquivos de dados originais e dumps do PostgreSQL não devem ser versionados neste repositório.
